## 2. 默认依赖：同样可以随代码使用的宽松协议

第一版**默认 Python / Node 依赖**只允许：

**MIT、MIT-0、Apache-2.0、BSD-2-Clause、BSD-3-Clause、ISC、0BSD**

另有登记在 [license-exceptions.json](license-exceptions.json) 的例外：

| 名称 | 许可 | 为何在树里 |
|---|---|---|
| SQLite（CPython `sqlite3`） | blessing / public domain | 不是 pip 包；禁止换成 GPL 构建的 SQLite |
| certifi（httpx 传递） | MPL-2.0 | 文件级 copyleft；本项目**不修改** certifi 源文件 |
| clr-loader（pywebview 传递） | MIT | pip 元数据缺 License 字段，以 upstream LICENSE 为准 |

CI 会扫描 `requirements.lock` / `requirements-dev.lock` 与 npm 许可表。默认树**禁止** GPL、AGPL、SSPL、LGPL、未知许可、BSD-4-Clause。PyInstaller（GPL + 冻结应用例外）只出现在 `requirements-build.txt`，**不是运行时依赖**，也不把本项目变成 GPL。

锁定版本见 `requirements.lock`。再分发 UI zip 时，以 zip 内 `THIRD_PARTY_NOTICES.md` 与 `licenses/`（完整许可正文，含 CPython/OpenSSL/Tcl-Tk 等原生库）为准；机器可读清单见 打包产出的 `sbom-huiyiku-<version>.cdx.json`（CycloneDX，覆盖冻结进 `_internal` 的组件）。

## 4. 使用者：录音同意、个人信息与外发

本工具处理**你提供的**音频和文本。录音行为、以及是否把转写发给第三方 API，合法性由**你**负责。下面是核验过的规则摘要，**不是法律意见、不是对某个案件的结论**。

本项目在 GitHub 全球分发。它会**便利化**录音转写，但**不是**窃听工具；文档与首次向导做主动告知，避免被理解为对秘密录音的放任。项目**不做同意管理数据库、不做地理位置检测、不提供法律意见**。

| 法域 | 规则 |
|---|---|
| 美国全员同意州（加州、佛罗里达、伊利诺伊、马里兰、马萨诸塞、宾夕法尼亚、华盛顿等） | 未经所有参会人同意录音在若干州可构成**刑事犯罪**；跨州通话适用更严一方（*Kearney v. Salomon Smith Barney*） |
| 欧盟 GDPR | 第 2(2)(c) 条家庭豁免仅限**纯粹**个人/家庭活动。工作场景录同事/客户通常落在豁免之外，录音者可能成为数据控制者，负告知、删除响应等义务。把文本发到欧盟外模型还涉及跨境 |
| 中国 PIPL | 第 72 条纯个人事务豁免（类似家庭豁免，不覆盖把他人会议发给境外模型）；向第三方提供个人信息应告知并取得同意。**第 28–29 条：生物识别属敏感个人信息，须单独同意**——声纹即生物特征 |
| 一般原则 | 秘密录音在多数法域有民事或刑事风险；会议内容还可能涉及隐私权 |

1. **默认不上传音频。** 本机 FunASR 转写走磁盘上的 WAV。配置了 LLM Key 并确认条款后，**转写文本**会发到该 API。未配 Key 时仍可导入、转写、校对、统计、导出。

3. **内网共享。** 默认关闭，只在设置页打开。打开后是明文 HTTP，同网段可直接访问。仅建议可信内网。
4. **首次启动确认。** 向导分别记录：理解须符合当地法律并获得参会人同意；同意把文本发到自己配置的 API。勾选**不能**代替守法，也不能代替与云厂商签约。

1. zip / 安装目录内保留 `LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.md` 与 `licenses/`（许可正文目录）。
2. 不要把真实 Key、`.env`、`meeting-data/`、用户录音打进发行包。

5. 默认依赖白名单见第 2 节；把 GPL 库加进默认 UI 依赖会破坏本项目的分发假设。
