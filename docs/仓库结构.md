# 仓库结构

本仓库只含会议库（huiyiku）源码。克隆后不要把 `meeting-data/`、`asr/` 权重、`.venv` 或真实 `app.json` 推进 GitHub。

```text
huiyiku/
├── src/huiyiku/            # 界面进程：FastAPI、Worker、引导窗口（无 torch）
│   ├── api/                # HTTP API 与 SPA 静态资源挂载
│   ├── asr/                # 调用独立 ASR CLI（不 import FunASR）
│   ├── db/                 # SQLite 模型、schema.sql、迁移
│   ├── domain/             # 分块、引用、统计、任务类型
│   ├── llm/                # 远程 BYOK：报告 / 问答 / 摘要 / 可选 embedding
│   ├── media/              # FFmpeg 查找与转码
│   ├── worker/             # 双执行道后台任务
│   ├── bootstrap.py        # 拉起 --serve/--worker，打开桌面窗口
│   └── paths.py            # 程序目录、meeting-data、asr 默认路径
├── src/huiyiku_asr/        # FunASR CLI；仅 ASR 进程加载 torch
├── web/                    # React + Vite；构建产物 web/dist 不入库
├── tests/                  # 无云厂商 Key、无真实录音
├── scripts/                # 许可/卫生门禁、Windows 打包
│   ├── repo_gates.py
│   ├── package_windows.py  # python scripts/package_windows.py --ui
│   └── release_zip.py      # zip 布局校验
├── packaging/              # 打进 zip 的 README 与空 ffmpeg/ 说明
│   └── ffmpeg/README.txt   # 用户自备 ffmpeg.exe
├── docs/                   # 方案、法律与许可、合规（本文档所在目录）
├── .github/workflows/      # ci.yml（测试+门禁）、release.yml（tag 打 UI zip）
├── LICENSE                 # Apache-2.0
├── NOTICE
├── README.md               # 给使用者
├── SECURITY.md
├── CONTRIBUTING.md
├── THIRD_PARTY_NOTICES.md
├── pyproject.toml          # 版本号唯一来源
├── requirements.lock       # UI 运行时（无 torch）
├── requirements-dev.lock
├── requirements-asr.txt    # 仅 ASR venv / ASR zip
├── requirements-build.txt  # 仅 PyInstaller
└── app.example.json        # 可提交的配置样例；真实 app.json 永不入库
```

## 运行时目录（本地，gitignore）

开发时默认都在仓库根（与 exe 解压目录同一规则）：

| 路径 | 内容 |
|---|---|
| `app.json` | 数据目录、监听地址、FFmpeg、asr_home |
| `meeting-data/` | SQLite、录音、转写、报告、secrets.json |
| `asr/` | `huiyiku-asr.exe` 或模型权重 |
| `.venv/` | UI 开发环境（不要装 torch） |
| `.venv-asr/` | 可选本机转写环境 |
| `web/node_modules/`、`web/dist/` | 前端依赖与构建产物 |
| `packaging/work/`、`packaging/dist/` | PyInstaller 工作区与发布 zip |

## 不要推上网

真实会议录音、转写、带真名的截图、`.env`、真实 API Key、`meeting-data/`、`asr/models`。公开前检查 `git log` 与 `git ls-files`。
